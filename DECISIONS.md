# Decisions

- Build original stdlib single regular-entry predicate model, not a filesystem
  mutation or replacement tool. Connected source comparison supports distinct gap.
- Require caller-declared selected parent access bits; do not silently embed prior
  DAC/ACL classes. Truth/mapping/ancestor/richer policy assumptions explicit.
- Parent write AND search, plus sticky parent-owner OR target-owner alternatives;
  ownership does not bypass prerequisites, target content bits have no effect.
- Full common validation precedes root/unknown/richer-context exclusion. Supported
  denial is complete, incomplete reports have no partial predicate decision.
- Reuse checked CLI help/diagnostic delivery lesson, with actual shutdown tests;
  mocked return values alone were insufficient in the prior ACL project.
- No upstream code/dependency executed/copied; original MIT recommended if approved,
  source/AI attribution retained. No Git/CI publication or initialization authorized.
- Local draft incorrect, no oracle adopted. Remote readiness stale and refresh out
  of scope; Codex retains security interpretation/planning, no paid fallback.

- Freeze13 full reports/domain before core. Fixed parser JSON avoids argv reflection.
- Both dirty public sinks detach on I/O failure; real normal/-O children distinguish
  native broken pipes from dirty short/flush and closed-Python/absent-stream seams.
- Guard exact key type/length before set membership. All review is implementing-agent
  evidence, not independent certification. Keep original research source gaps.
